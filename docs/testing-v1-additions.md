# 固定後に追加した操作境界

`testing-v1-coverage.md` の固定時点の表に対し、以下を追加する。元のテスト、入力、期待値、ハッシュは変更しない。

`tests/navigation_edges_v1.rs` の8件:

| ケース | 追加した観測 |
| --- | --- |
| A12/A49 | 2本目の指が加わった操作で起動・登録をしない |
| A12/A49 | 移動9dpでは600msの長押しが有効、起動はしない |
| A09/A49 | 縦横比1.5未満ではホームを維持 |
| A10 | 途中から先頭に到達する同一ジェスチャーでは一覧を閉じない。開始時は先頭以外、終了時は先頭という前提も検査 |
| A12 | Touch EndとPointerGoneを含む実入力の指離し後に慣性移動が続き、誤起動・登録しない |
| A11 | Back後に設定を開き直しても未送信の地域入力を復元しない |
| A02/A11 | 設定画面のHOMEでホームへ戻り入力欄を外し、保存済み明暗は保持 |
| A11/A51 | Backで取り消した読み入力の遅い完了通知を保存しない |

慣性移動の検出はホストUIの振る舞いであり、実機FPSの代用ではない。Platform入力完了通知を制御した試験を、Androidの実ダイアログのBack成立と同一視しない。
