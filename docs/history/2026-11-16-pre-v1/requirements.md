# Quiet Launcher 要件定義案

更新日: 2026-11-16。後続のユーザー指示により仕様と作業範囲を更新した。最新の具体契約は [追加契約](contracts-2026-11-16.md) と、その後の訂正（収容不可は省略せずエラー通知）を優先する。保存・検索・キャッシュ等にはテスト先行で実装を追加している。

この文書はユーザーの依頼を基準にする。現在のコードや既存テストの動作を理由に、要求を削ったり、誤った挙動を正解にしたりしない。要件に対応する受け入れケースは [受け入れテスト計画](acceptance-plan.md) に記載する。

未確定部分を具体化した [仕様案](spec-proposal.md) を別に整理した。基準実機はユーザー指定の OPPO Reno7 A / Android 13。仕様案の他の詳細は、採用が決まるまで提案として扱う。

全体の未確定点と整合が必要な箇所は [要件の点検結果](requirements-audit.md) に記録している。要件 ID とケースが対応していても、その期待結果まで確定したことにはしない。

## 1. 合意した方向と変更点

- Android のホームアプリを、Rust で実装する。テキストと記号を中心とした dumb phone の見た目にする。
- 選んだインストール済みアプリをホームに並べる。ホームから上スワイプで、独立したアプリ一覧を下から開く。
- Fokus を参考にした画面内の検索を使う。ホーム・アプリのヘッダーと「アプリ ↑」の案内は表示しない。
- 時計・日時・天気・スクリーンタイム・メディア操作・外部ウィジェットの情報をホームに表示する。
- 手入力でメモを作る「テキストウィジェット」は不要。外部ウィジェットの情報を文字として表示する機能は残す。
- hide app を追加する。**ホーム・アプリ一覧・検索結果のすべてから隠す**。
- **一覧のアプリ名の長押しを操作メニューに変更**し、「ホームに追加／ホームから外す」「非表示」を選べるようにする。長押しだけでお気に入りが切り替わる旧操作は、この合意により置き換える。
- **非表示でもホームの登録と並び順を保持**し、解除したら元の位置へ戻す。
- 要件、テスト、実装の順に進める。テストの期待値を実装に合わせて変更しない。

## 2. 用語と仕様案の境界

「アプリ」はインストールされたアプリの単位、「起動項目」はそのアプリが公開する起動先を指す。同じアプリが複数の起動項目を持つ場合と、異なるアプリが同じ表示名を持つ場合を区別する。

次の詳細は、この要件案として提案する。まだユーザーが個別に指定したものではない。

| 論点 | 仕様案 |
| --- | --- |
| 非表示の単位 | 表示名や起動項目単位ではなく、アプリ単位。同じアプリのすべての起動項目を隠す |
| 解除の場所 | 設定の「非表示アプリ」から解除する。通常のアプリ一覧や検索に、解除用の例外表示を設けない |
| 更新・再インストール | 同じアプリの更新、表示名変更、起動項目追加、アンインストール後の再インストールでも非表示を維持する |
| 外部ウィジェット | 非表示はアプリの起動項目に適用する。登録済みの外部ウィジェットは勝手に削除せず、ウィジェットの設定から個別に管理する |
| 保護の範囲 | Quiet の表示と起動操作の整理機能。Android 本体の設定・他のランチャー・他アプリからの起動を制限する機能にはしない |
| 初期状態 | 非表示アプリなし。既存ユーザーのホーム登録・設定・外部ウィジェットを引き継ぐ |
| 検索の表記ゆれ | ひらがな・カタカナ・ローマ字と、辞書にある英語名の読みをそろえた完全一致へ拡張する。部分一致・あいまい検索は別の将来要件 |
| スクリーンタイム | 現在の画面インタラクティブ時間の定義を維持。「今日00:00〜現在」と「直近24時間」を切り替える。ロック中を除外する以前の案は今回採用しない |
| 天気 | 設定した地域の天気を表示。自動現在地取得は含めない。地点指定方法・更新間隔の数値はテスト凍結前に確定する |

## 3. 機能要件

以下の ID はテストと検証記録で共通に使う。状態や表示結果を規定し、特定の構造体、内部関数、描画ライブラリ、フィルタリング手順は規定しない。

### アプリ本体とホーム

| ID | 要件・合格条件 |
| --- | --- |
| BASE-01 | アプリ本体の独自ロジックを Rust で実装する。独自 Java / Kotlin のアプリソースを追加しない。Android 標準クラスと依存ライブラリの利用は許容する |
| BASE-02 | Android にインストールでき、標準ホームとして選択できる。起動・他アプリからの復帰・画面消灯からの復帰・Activity 再作成で、操作できるホームを描画する |
| BASE-03 | 更新 APK は同じアプリとして上書きインストールでき、設定を維持する。ダウンロードするファイルとインストール対象の APK が分かる |
| HOME-01 | ユーザーが選んだ起動項目だけを指定した順番でホームに表示する。ホームは1画面に収める。収容不可の追加や文字サイズ変更は反映せず、詳細を開かなくても「ホームに収まりません」と分かるエラーを通知する。既存の登録を勝手に削除・無通知で省略しない。追加・解除・並べ替えができ、重複登録しない |
| HOME-02 | アプリ名の通常タップで、その名前に対応した起動項目を開く。同名の別アプリ・別起動先を取り違えない |
| HOME-03 | 現在の時計・年月日・曜日を表示し、分・日付・端末のタイムゾーンの変更を反映する |
| HOME-04 | テキストと記号を中心に表示する。ホーム・アプリの常設ヘッダー、「アプリ ↑」や同等の案内、手入力のテキストウィジェットの追加・編集・表示を設けない |
| HOME-05 | 詳細説明、権限設定、詳細なエラーは設定画面や必要時の詳細表示へまとめる。初回案内が通常のホーム操作を占有しない |
| HOME-06 | ホームの空白部分の長押しと、一覧の三点メニューの両方から設定を開ける。ホームのアプリ名には操作メニューを出さず、背景の長押しと取り違えない |

### 一覧・画面遷移・検索

| ID | 要件・合格条件 |
| --- | --- |
| NAV-01 | ホームで1回上にスワイプすると、独立したアプリ一覧が下から滑らかに開く。ホームの長さに依存して何度もスクロールする必要がない |
| NAV-02 | 一覧の先頭で下へ引くとホームへ戻る。一覧の途中から先頭へスクロールしている間は、一覧を閉じない |
| NAV-03 | 戻る操作は設定・操作メニュー・IME表示中もホームへ戻し、検索語や一覧位置をリセットする。ホームボタンからもホームへ戻る。Android連携まで満たしたかは別途検証する |
| NAV-04 | スクロール、フリック、長押し、キャンセルされたタッチで、アプリの誤起動や意図しないホーム登録変更を起こさない。指を離した後の慣性を維持する |
| LIST-01 | インストール済みの起動可能な項目を一覧に出す。インストール・更新・アンインストールを反映し、同名の別項目を消さない。非表示指定はこの要件より優先する |
| LIST-02 | 一覧の追加・解除操作と、アプリ名の長押しメニューからホームの登録を変更できる。長押しメニューを開くだけでは登録も起動も変更しない |
| SEARCH-01 | 一覧上部に装飾を抑えた入力欄を置く。検索ダイアログや画面内の確定ボタンを経由せず、入力・削除・貼り付けに応じて結果を更新する。スクロール中も入力欄を利用できる |
| SEARCH-02 | 日本語 IME の入力・変換・確定を利用できる。一覧を開いたときは入力を開始でき、ホームに戻る操作では検索語を消す。入力欄から再入力できる。IME の下に操作対象が隠れてアクセス不能にならない |
| SEARCH-03 | 空の検索語では全表示対象、名前が完全一致する検索語では一致した全項目、不一致や部分一致だけなら0件を表示する。文字と読みの正規化は追加契約を基準にする |
| SEARCH-04 | 長い一覧をスクロールした後に検索しても、一致した先頭の結果が入力欄の裏や画面外へ隠れない。結果0件と読み込み中を区別する |
| SEARCH-05 | 検索方式を将来差し替えられる。差し替え後もホーム登録・非表示・画面操作・保存の約束を維持する |

### ホームに表示する情報

| ID | 要件・合格条件 |
| --- | --- |
| INFO-01 | 地域を設定すると、その地域の実際の天気と気温、取得時刻を表示する。更新・地域変更・解除を扱える。未取得や通信失敗を架空の正常値で表示しない |
| INFO-02 | 天気の取得に失敗した場合、取得済みの情報とその取得時刻を区別できる状態で保持し、復旧後に更新できる。通信待ちでスクロールや検索を停止させない |
| INFO-03 | スクリーンタイムは、今日または直近24時間の選択した集計範囲で、現在の画面インタラクティブ時間の定義を維持して計算する。許可なし・履歴未取得を0分と同一視しない。日付またぎや重複イベントで過大計上しない |
| INFO-04 | 操作可能なメディアセッションの実際の状態を表示し、選択対象だけを記号ボタンで操作する。複数対象は横スワイプで切り替え、対象なしでは領域を隠す。権限・非対応操作・対象消失も扱う。詳細は追加契約を参照する |
| INFO-05 | 情報の表示設定、天気の地域設定、明暗設定、既存の電池残量表示を維持する。明暗変更後も文字とシステムバーを読める |

### 外部ウィジェット

| ID | 要件・合格条件 |
| --- | --- |
| WIDGET-01 | インストールされた提供元からウィジェットを選び、Android の許可と提供元の初回設定を経て登録できる。許可・設定のキャンセル後も操作を継続できる |
| WIDGET-02 | 読み取り可能な文字・説明文を文字または記号で表示する。元の UI の完全再現は要求しない。画像しかない等の非対応内容を架空の情報で補わない |
| WIDGET-03 | 正しい提供元名をホームと設定に表示する。内容を取得できなくても、取得済みの名前を「ウィジェット」に置き換えない。許可待ち、読み取り失敗、再起動でも名前を保持する |
| WIDGET-04 | 登録済みウィジェットを削除できる。1件が非対応でも、他のウィジェットの名前・情報・ホームの操作を壊さない |

### hide app

| ID | 要件・合格条件 |
| --- | --- |
| HIDE-01 | 非表示にしたアプリの起動項目は、ホーム、通常一覧、すべての通常検索結果に出さない。完全一致で入力しても出さない |
| HIDE-02 | 第2節の案に従い、同じアプリの全起動項目へ適用する。同じ表示名の別アプリには適用しない |
| HIDE-03 | 一覧のアプリ名の長押しで、「ホームに追加／ホームから外す」と「非表示」を選べる。メニューを閉じるだけなら何も変更しない。非表示操作で対象アプリを起動しない |
| HIDE-04 | 非表示操作を完了したら、そのアプリが表示中の検索結果・ホームからも消える。他のアプリの順番、登録、検索結果を不要に変更しない |
| HIDE-05 | ホーム登録と並び順を保持したまま非表示にする。解除時には元の位置に戻す。その間に他のアプリを並べ替えても、その操作を巻き戻さない |
| HIDE-06 | 設定の非表示アプリ管理から一覧・解除できる。通常一覧には出さず、非表示管理画面では対象を識別できる名前と必要な補助情報を示す。ホーム並べ替え等の通常管理画面には出さない |
| HIDE-07 | 非表示・解除を繰り返しても重複・登録消失を起こさない。プロセス終了、再起動、アプリ再列挙、APK 更新後も設定を保持する |
| HIDE-08 | 第2節の案に従い、表示名変更、アプリ更新、新しい起動項目、アンインストールと再インストールで非表示を解除しない |
| HIDE-09 | 検索方式を差し替えても、非表示のアプリを検索経由で再表示しない。古い画面・検索結果からの遅れたタップでも、Quiet から非表示アプリを誤起動しない |
| HIDE-10 | 非表示の変更で、登録済み外部ウィジェット、天気、スクリーンタイム、メディア設定を消さない |

### 保存・表示・性能

| ID | 要件・合格条件 |
| --- | --- |
| DATA-01 | お気に入りと順番、表示設定、地域、外部ウィジェットの登録と名前、非表示設定を端末内に保存し、再起動後に復元する |
| DATA-02 | 既存の設定に非表示の項目がなくても読み込め、勝手にアプリを隠さない。廃止した手入力ウィジェットの古いデータで他の設定を失わない |
| DATA-03 | 壊れた設定や保存失敗を知らせ、壊れた元ファイルを初期設定で黙って上書きしない。保存に失敗したのに再起動後も保存済みと扱わない |
| DATA-04 | アプリ一覧・非表示設定・スクリーンタイム・外部ウィジェットの内容を外部へ送らない。天気に必要な通信の条件を説明できる |
| UI-01 | 小さい縦画面、横画面、大きい文字設定で、長いアプリ名・検索語・ウィジェット内容・操作メニューが横にはみ出さない。必要な操作はスクロールや省略表示後も利用できる |
| UI-02 | ステータスバー、ナビゲーションバー、画面の切り欠き、IME と操作対象が重なってアクセス不能にならない |
| PERF-01 | スマートフォンの指によるスクロールと画面遷移が滑らかである。アプリ数や通信・ウィジェット処理の待ち時間で入力を長時間止めない。合否の数値条件は第4節で確定する |
| COMPAT-01 | 対象案は Android 9（API28）以降、配布は arm64、エミュレーター検証は x86_64。最低対応 API と代表 API の両方で、標準ホーム・IME・権限・復帰の契約を検証する |

| ID | 要件・合格条件 |
| --- | --- |
| FONT-01 | 文字サイズを設定から変更し保存する。ホーム・一覧・検索入力に反映し、1画面に収まらなくなる変更は反映せずエラー通知する |
| CACHE-01 | アプリ一覧の正常なディスクキャッシュを初回描画から使う。更新中や取得失敗でも空にしない |
| CACHE-02 | 画面遷移・端末情報更新・検索ごとにアプリ全件を再列挙しない。インストール状態・言語の世代が変わったときに更新する |
| CACHE-03 | 名前と起動先・世代だけを保存し、アイコンや全画面の描画結果を常駐させない。メモリの一覧は共有する |
| CACHE-04 | キャッシュの順番でホーム登録や起動先を関連付けない。非表示設定を読み取れない場合はキャッシュからの通常表示も抑止する |
| SEARCH-06 | ひらがな・カタカナ・主なローマ字表記と、辞書にある英語名の読みで相互検索する。未知の英語名の読みをユーザーが追加できる |
| WIDGET-05 | 実画面の表示をE2Eで確認できる環境を用意する。候補となる最低合格ラインはユーザーに確認し、承認前に正式採用しない |

## 4. テスト凍結前に確定する詳細

数値・境界が未確定の項目を、実装の既存値で埋めて確定したことにしない。

| 項目 | 提案と残る判断 |
| --- | --- |
| 第2節の仕様案 | 非表示のアプリ単位、復元場所、再インストール、ウィジェットとの境界などを要件案としてレビューする |
| 非表示中の並べ替え | 画面に出る項目間の並べ替えを尊重し、解除後に隠れた項目も元の順序上の位置へ戻す案。削除による位置の繰り上がりを含め、具体例は受け入れケース A18 に固定する |
| 天気 | 地点を指定する入力方法と、定期更新の間隔を決める。未設定、古い値、通信失敗、再試行の期待結果は先に固定する |
| スクリーンタイム | 既存の集計定義を維持し、今日／直近24時間を選択する。ロック中を除く先の提案は採用しない |
| スクロール性能 | 基準実機は OPPO Reno7 A / Android 13 で確定。60Hz／90Hzでのフレーム時間・操作応答・合格割合・測定条件の案は仕様案に記載。エミュレーターや描画件数だけで実機の滑らかさを合格にしない |
| データ読み取り失敗 | 非表示設定を読み込めなかったときの一覧表示を決める案は、エラーを示して通常一覧・検索を一時停止し、壊れたファイルを保持する。復旧操作の導線も受け入れ条件にする |

## 5. 今回含めないこと

- 手入力のテキストウィジェット、外部ウィジェットの見た目の完全再現。
- 部分一致・あいまい検索。今回の読み対応・英語名の読み辞書・差し替え可能性・非表示の維持は対象。
- PIN・生体認証によるアプリロック、アンインストール、Android 全体からのアプリの秘匿。
- Fokus 全機能の移植。カテゴリ、プロファイル、ロック操作などは別要件。
- 全メーカーのすべての外部ウィジェットとの互換性。対応・非対応を判断する代表例と境界はテストする。

## 6. 完了の定義

全要件 ID に受け入れテストを対応させ、合意した期待結果を凍結した後、テストが失敗することを確認してから実装する。既存機能にも、新しい要件ベースの不足テストを先に追加する。

「テストが17件通った」「コードカバレッジが高い」「起動中の Activity 名が Quiet だった」だけで、全要件を満たしたと判定しない。画面の描画、入力、実際の Android 連携、性能まで、対象条件の証拠を対応付ける。未実行・スキップ・環境不足は未検証とし、合格に含めない。

今回追加したテストの通過と、全体要件の充足は区別する。メディアのAndroid連携、すべての戻る経路、実機性能、外部ウィジェットの正式合格ラインなどは引き続き検証・確認が必要。
