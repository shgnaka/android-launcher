正式な仕様・受け入れの固定対象は `docs/requirements-v1.sha256` に記録した。ルートディレクトリから次で照合できる。

```sh
sha256sum -c docs/requirements-v1.sha256
cargo run --offline --no-default-features --example check_contracts
```

前者は今回の仕様・計画・判断の版を固定し、後者は従来の凍結済み試験を保護する。仕様のハッシュ照合を製品の機能テストに数えない。

現在の実装が満たさない場合も、この基準を緩めない。代表的な残件は、すべてのBack/HOME経路、メディアセッション連携、ウィジェットの途中失敗と復旧、天気の詳細境界、画面時間の取得状態の識別、変更反映期限、実機の性能・メモリ計測。これらは仕様の質問待ちではなく、テスト・実装・実行の作業である。
