# 外部ウィジェットの最低合格ラインの確認

確定日: 2026-11-16。ユーザーの「全体の要件を確定させて」に伴い、以前の「合格ラインを設定したら確認する」という指定に従って個別に確認した。

提示した3点:

1. 提供元の正しい名前と本文がホームに実表示される。
2. Quietのプロセス再起動後も復元する。
3. 設定から削除すると消える。

ユーザー回答: **「この3点で確定する（推奨）」**。

この3点を [全体要件v1.0](requirements.md) の WIDGET-05 に採用した。本文の動的更新をこの最低ラインへ追加する選択肢は採用しない。ただし製品の更新動作・キャンセル・非対応表示等の個別要件は別途検査する。

既存の試験は [前回の検証記録](nov16-validation.md) のとおり、実提供元と実画面OCRで3点に成功している。その記録・凍結済み試験・既存のJSONは過去時点の証拠として変更しない。確認が済んだことと、試験を新たに再実行したことを混同しない。
