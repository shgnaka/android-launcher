# v1試験の対応範囲

要件の正本は `requirements.md`、ケース群の正本は `acceptance-plan.md`。この表はテストの対応範囲であり、合格表ではない。部分的な自動化をケース群全体の完成として数えない。残件を実装修正前に追加・固定する。

略記: `logic` = `tests/requirements_v1.rs` 内の各モジュール、`screen` = 同 `screens`、`bounds` = `tests/boundaries_v1.rs`、`native` = `tests/android_requirements_v1.rs`、`apk` = `tests/apk_requirements_v1.rs`。各ファイルのテスト名に対象の振る舞いを記した。旧34件・ウィジェット最低3点も引き続き実行対象。
